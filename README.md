# Robot Vacuum Cleaner FSM
This repository contains two implementations of a finite state machine (FSM) for a robot vacuum cleaner:

## 🔧 OOP C++ FSM (Terminal Simulation)
Located in `OOP_CPP_FSM/`, this simulation uses:
- Dynamic state switching
- Polymorphic state logic
- Terminal-based debug output

## 🖼️ Qt GUI FSM (Interactive Simulation)
Located in `Qt_GUI_FSM/`, this app features:
- Interactive FSM visualization
- Animated robot and cat behavior
- Cleaning/docking logic and battery level display

## Build Instructions
See each subfolder for build steps using CMake or Qt Creator.
